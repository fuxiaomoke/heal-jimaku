# Heal-Jimaku (治幕) v1.0

> **开发中** —— 这里是一个空工地，目前还没有能跑的东西。

- 旧版（PyQt 世代，最后一版 v0.2.5）在 [`main`](../../tree/main) 分支：代码、文档、安装包都在那边；
- 旧世代代码的终点打了 tag `legacy-pyqt`；
- 本分支的第一个提交把旧树整体清掉了，之后只会长出新代码。

## 它是什么

一个通用工具：把任何来源的词级时间戳 JSON 变成断句自然的 SRT，并保留免费 / 付费云端转录。
（旧版的完整说明见 `main` 分支的 README。）

## 为什么另起一摊

旧版是 PyQt6 时代的产物，界面的表现力和代码的可维护性都已经到顶。v1.0 换掉整个前端框架重写：
断句规则、提示词这些"知识"从旧代码里搬过来，但**目录结构不搬**，所以这里看不到旧目录。

旧代码随时可以查：

```bash
git checkout main          # 或 tag legacy-pyqt
```
